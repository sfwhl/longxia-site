# 🧠 人和 AI 一样，是个可增量训练的系统

> **感悟**：突然想到人和 AI 一样，不也是每天在学习技能，能力变得越来越多，可以完成复杂的任务。接到新的任务都得拆解任务，一步步推进完成。

## 📍 背景

- **日期**：2026-07-15 周三，早上
- **触发**：看到自己每天在学 skill（Hermes 装的 21 个 skill），意识到**人 = 自己的 LLM**
- **状态**：程序员 + AI 用户，**第一次把自己当 LLM 来理解**

## 🎯 一句话主旨

> **人不是机器，而是一个"可增量训练、有长期记忆、能做 CoT 推理的生物 LLM"。**

## 🔬 展开：人和 AI 的对应

| 人类行为 | AI 对应概念 | 含义 |
|---------|------------|------|
| 每天学习技能 | 增量训练 / 增量学习 | **每天都在给"自己这个模型"加能力** |
| 能力越来越多 | Skill 系统扩展 / 多任务学习 | **Skill 库是慢慢建的** |
| 完成复杂任务 | 多 Skill 协作 / Function Call | **复杂任务 = 多个 skill 串联** |
| 接新任务拆解任务 | **Chain-of-Thought (CoT)** | **任务分解 = CoT** |
| 一步步推进 | 逐步推理 / 工具调用循环 | **任务推进 = ReAct 模式** |
| 记忆 / 日记 | 长期记忆 / RAG | **日记 = 我这个人的 vector store** |
| 复习旧笔记 | 检索增强 | **RAG 让旧知识被调用** |
| 跨领域组合 | Multi-Agent | **不同视角 = 不同 agent 协作** |
| 早起做自己 | System prompt 重写 | **重新定义"我是谁" = system prompt 重写** |

## 💡 这个视角的 4 个好处

### 1️⃣ 接受不完美
- AI 不是一开始就会所有事，**人也不是**
- 不会 = 数据不够，**不是你不聪明**
- 解决方案：**增量训练**（多学、多练）

### 2️⃣ 技能要积累
- AI 的 skill 系统是慢慢建的
- 人的能力也是——**今天装 1 个 skill，明天装 1 个，年底就是 21 个**
- 你的 `~/.hermes/longxia/skills-registry/` 就是**你这个人 LLM 的 skill 清单**

### 3️⃣ 任务要拆解
- AI 不会跳步，人也不能跳步
- 大任务 = N 个小任务 → **CoT 思维链**
- 复杂任务 = 多 skill 组合 → **Function Call 编排**

### 4️⃣ 长期记忆要维护
- AI 有 RAG / vector store
- 人有日记 / 笔记 / skill 库
- **你今天的 `~/.hermes/longxia/` 就是你这个人的"长期记忆系统"**

## 📌 实践：把自己当 LLM 来"训练"

### 每日训练循环（每天 30 分钟）

```
1. 早上：System Prompt 检查
   "今天我要做什么样的人？"

2. 白天：Context 收集
   微信读书划线、Skill 使用、问题解决

3. 晚上：增量训练
   拉今天的划线 → 写入 journal → 复盘
   跑 daily.sh → 生成总结 → 反思

4. 每周：版本迭代
   对比 v1.0 和 v1.1 → 哪里进步了
```

### 任务接单协议（CoT 模板）

每次接到任务，先回答：

1. **这是什么类型的任务？** （读 / 写 / 分析 / 实现）
2. **需要哪些 skill？** （已装的有吗？没有就找）
3. **怎么拆解？** （3-5 个子步骤）
4. **先做哪一步？** （最小可行验证）
5. **怎么验证？** （5 问自检 + 复盘）

> 
> 昨天的你 v1.0，今天的你 v1.1，明天的你 v1.2。
> **进步看得见。**
