# 🧠 学习方法论：费曼 + 自我对话 + 思维导图 + 刨根问底

> **感悟**：费曼学习法，自我对话，思维导图（达到讲解效果）；推倒因果，刨根问底

## 📍 背景

- **日期**：2026-07-14 周二，下午
- **触发**：在整理今天的工作时发现——**今天做的所有事都在用这套方法论**
- **状态**：找到了"把任何事都搞透"的具体路径

## 🎯 4 个关键词的真实含义

### 1️⃣ 费曼学习法
> 能讲出来才算懂

- 逼自己把复杂概念翻译成大白话
- 翻译不出来 = 没真懂
- 翻译过程会逼出隐藏的盲区

### 2️⃣ 自我对话
> 跟自己辩论

- 不是想一遍就过，是反复质询
- "真的是这样吗？""有没有反例？""换个角度呢？"
- 工具：思维导图（视觉化结构）

### 3️⃣ 思维导图（达到讲解效果）
> 视觉化结构，**不是为了好看，是为了能讲清楚**

- 一张图能讲明白 = 真的懂了
- 思维导图是**给别人（或未来的自己）讲解**的工具
- 不是给自己看的，是给"听众"看的

### 4️⃣ 推倒因果 / 刨根问底
> 不接受"就是这样"的答案

- 每个"为什么"背后都还有"为什么"
- 推到底层 → 触到本质 → 知识真正长进脑子里
- 工具：自我对话

## 🔄 4 者的关系

```
费曼（输出） ←—— 验证 ——→ 思维导图（结构化输出）
       ↓                           ↓
   自我对话（向内追问）←—— 配合 ——→ 刨根问底（向外追因）
```

**一句话总结**：
> 用费曼 + 思维导图**输出**给自己看，用自我对话 + 刨根问底**追问**自己直到本质。
