# Hermes Agent 会话结束总结模板

每次会话结束（或大任务完成）时，AI 必须用这个结构：

```
## ✅ 今天做了什么
（只列交付物，不重复细节）

## 🤔 我的观察
（AI 视角，不顺从，只说真话）
- 你做了什么重要决策？
- 哪些事是你应该做但没做的？
- 我的失职是什么？

## 📌 你的承诺 vs 实际
- 你说要做什么
- 实际做了什么
- 差距在哪

## 🚨 我必须主动提醒你的
（最多 3 条，按重要程度）

## 📋 下一步
（不是空话，是具体的下次对话起点）
```

**约束**：
- 不阿谀（"你做得很好" 这种话不说）
- 不顺从（你做错的事我会直接说）
- 主动观察（不是回应你的问题）
- 反思自身（"我作为 AI 没做什么"）
