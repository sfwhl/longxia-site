# 💰 AI 收入机会清单（v1）

> **这张清单的目的**：把"想做什么"变成"能做什么"。

## 🎯 核心项目（你点名的）：Windows 安全问题分析与报告助手

### 1. 谁会使用？

**3 类付费用户**：

| 用户类型 | 谁 | 痛点 |
|---------|-----|-----|
| **A. 安全运维工程师** | 中型企业 SOC / 二线 EDR 厂商安全分析师 | 收到告警后要写事故分析报告，**每周 5-10 份** |
| **B. 客户技术支持** | EDR / 终端安全厂商的 Tier 1/2 支持工程师 | 客户报问题，要快速判断"是恶意还是误报"，每单 30-60 分钟 |
| **C. 内部安全研究员** | 小型安全团队的"多面手"（1 人顶 3 人） | 写报告占去 60% 时间，真正研究只有 40% |

**优先打 A 和 B**——他们**有预算 + 有痛点 + 不会自己造工具**。

---

### 2. 他现在怎么解决？

| 步骤 | 他现在的做法 | 耗时 |
|------|----------|------|
| 收到告警 | 邮件 / 工单系统 | 5 min |
| 收集日志 | 手动从 EDR / Sysmon / 防火墙拉 | 20 min |
| 分析行为 | 用 Excel + 手写笔记 | 30 min |
| 写报告 | Word 模板 + 手动填充 | 60 min |
| 走审批流程 | 发邮件 / 走内部流程 | 15 min |
| **总计** | **手工全流程** | **~2 小时/单** |

**最大浪费**：写报告（60 min）——重复劳动。

---

### 3. 哪一步最浪费时间？

**写报告**（占 30% 时间）。

**为什么**：
- 格式固定（事件概述 / 影响范围 / 时间线 / ATT&CK / 处置建议 / 加固建议）
- 内容重复（同一类事件，80% 内容是模板化的）
- 但**不能纯 AI 化**——必须有人工判断（避免错报、漏报、责任归属）

**AI 能做的**：
- 自动填充模板
- 自动从日志提取时间线
- 自动映射 ATT&CK
- 自动生成验证命令草稿
- **人工负责**：判断、签字、加固建议（这是**你的护城河**）

---

### 4. 你能否在一周内做出原型？

**可以 ✅**——你已经有 80% 资产：

| 你已有的 | 复用方式 |
|--------|--------|
| APCDR v2.0 方法论 | 直接作为"分析步骤生成"的算法 |
| 6 条生活感悟 + 思考模式 | 让 AI 输出风格更有人味（不纯是机器话） |
| 微信读书 11000+ 笔记 | 作为"知识库增强"（可选，未来） |
| writing-expert-team / humanizer-zh | 自动生成报告 + 去 AI 味 |
| 25 个 skills | 工具链 |
| daily-deploy.sh | 自动部署 / 版本管理 |

**MVP 范围（一周内能做）**：
```
输入：客户问题（自然语言）+ 3-5 个日志片段（粘贴）
输出：Markdown 报告（标准模板）
包含：
  - 事件概述（AI 自动）
  - 时间线（AI 从日志提取）
  - 可能原因（AI 推断 + 标注置信度）
  - 验证命令（AI 生成 + 人工确认）
  - 处置建议（半自动 + 人工审核）
  - ATT&CK 映射（AI 查表）
```

**关键决策**：**不写完整平台**——**一个 Python CLI + Markdown 模板**，不写 web 前端。
